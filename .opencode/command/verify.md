Verifikasi kualitas proyek:

1. Jalankan `npm run lint`.
2. Jalankan `npx tsc --noEmit`.
3. Jika dua langkah di atas bersih, jalankan `npm run build`.
4. Perbaiki setiap error pada sumbernya (jangan menonaktifkan aturan).
5. Ulangi hingga bersih, lalu laporkan hasil ringkas.

Konteks tambahan dari pengguna: $ARGUMENTS
